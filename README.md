## 🚀 Getting Started

Follow the steps below to set up and run this project locally.

### 📋 Prerequisites

- Node.js (v18+ recommended)
- npm / yarn / pnpm

### 💻 Installation & Execution

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/akshithnallaginnela/github-widget.git
   cd github-widget
   ```

2. **Setup and Run:**
   ```bash
# 1. Install dependencies
npm install

# 2. Run the project
npm run dev
   ```
